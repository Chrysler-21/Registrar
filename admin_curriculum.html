1 Create a draft

Start from a blank placeholder or import a DOCX into a draft. Drafts are editable and do not affect the active current offering until you choose a lifecycle action later.

2 Build the course plan

Open the draft, attach shared catalog courses, and place each course by year and semester. Course identity and relationships stay in Course Catalog; Curriculum Management only places existing shared courses into the outline.

3 Choose lifecycle status

When the draft is ready, choose Set Current, Mark Legacy, or Archive. Setting a curriculum current will move the previous current offering for that program to Legacy.
